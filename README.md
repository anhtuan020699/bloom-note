# BloomNote

Quà tặng 20/10: thiệp, hoa, nhạc.

- `client/` — Next.js (cổng 5173)
- `server/` — NestJS + Postgres (cổng 4000)

## Chạy local

```bash
cd server && npm install && npm run dev
cd client && npm install && npm run dev
```

Web: http://localhost:5173  
API: http://localhost:4000
